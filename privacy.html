Privacy Policy

Last updated: October 7, 2026

Personal Mail Calendar MCP is a private, single-user tool. It is used only by its developer, with the developer's own Google accounts.

Data accessed

With the owner's consent, the app requests these Google permissions: read Gmail messages, create and manage Gmail drafts, read Google Calendar, and create Google Calendar events.

How data is used

Data is used only to let the owner read their own mail and calendar and to create drafts and events on their behalf. The app does not send email.

Storage and sharing

Sign-in tokens are stored only on the owner's own computer. Email and calendar content is not copied to any server operated by the developer, is not sold, and is not shared with third parties. Content is passed only to the AI assistant the owner chooses to use, at the owner's request.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files removes all stored credentials.
